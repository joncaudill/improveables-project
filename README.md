## Description

This repository contains a collection of projects and utilities, each with clear
improvements and optimizations that can be made.   I needed some starter projects 
to test new tools, and to test the code capabilities of LLMs, and rather that looking 
for open source projects each time, I thought I'd write some basics on my own. 
I then decided to make it into a repository so I can reach it wherever.  

## Projects

### 🌈 RainbowOut
A .NET console application that uses ConsoleColor and Console.Write to take an input 
string and output it to the console in a variety of colors.  Sparsely commented 
as thats one of the things I needed to test.

**Tech Stack:** C# (.NET 8.0)

**Location:** [`RainbowOut/`](./RainbowOut/)

## Getting Started

To get started with any of the projects in this repository, follow the instructions below or refer to the individual project README files for specific setup instructions.

### Prerequisites

Check the individual subprojects' REAME for prerequisites and build info

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/joncaudill/improveables-project.git
   ```

2. Navigate to the project directory:
   ```bash
   cd improveables-project
   ```

3. Choose a specific project and follow its setup instructions (see project-specific README files).
